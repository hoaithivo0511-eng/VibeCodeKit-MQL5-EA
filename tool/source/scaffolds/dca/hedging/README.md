# dca / hedging

Dollar-cost averaging EA with timed entries + drawdown freeze.

Render via:

```bash
python -m vibecodekit_mql5.build dca \
    --name MyEA --symbol EURUSD --tf H1 --stack hedging
```

See the [archetype catalogue](https://github.com/hoaithivo0511-eng/VibeCodeKit-MQL5-EA/blob/main/tool/source/docs/COMMANDS.md) and the [quickstart](https://github.com/hoaithivo0511-eng/VibeCodeKit-MQL5-EA/blob/main/tool/source/docs/QUICKSTART.md) for context.
