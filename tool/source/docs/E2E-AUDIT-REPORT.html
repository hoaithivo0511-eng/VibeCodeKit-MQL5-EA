Executive result

The alpha.2 report identified a valid P0 provenance weakness: realistic-looking files and a permissive manifest could make the standalone attestation command return release_eligible=True. The finding was reproduced, then fixed in alpha.3.

Scope limitation: this environment has no Windows-native MetaEditor or MT5 Strategy Tester. Compile, backtest, forward-test and live gates therefore remain UNTESTABLE. This report proves gate honesty and package behavior; it is not trading-performance or live-readiness evidence.

Release-provenance gate

Release-looking evidence must now satisfy all of the following:

  • evidence/manifest.json schema 2.0 with release_eligible=true and a matching summary.
  • Compile and backtest blocks with source, command, tool_version, host and recorded_at_utc.
  • Trusted source classification: actual/remote MetaEditor and actual/remote MT5 Strategy Tester only.
  • SHA-256 records matching every core artifact; a non-trivial EX5 binary; parseable MT5 XML with trade/performance metrics; valid stress/review JSON.
  • Verified evidence hash chain.
